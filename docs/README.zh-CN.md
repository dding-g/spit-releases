# spit

[English](../README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md)

适用于 Windows/macOS 的轻量托盘应用，用于快速记录单行笔记并保存为本地 Markdown。简洁的输入窗口会预先加载，文件写入在后台进行。英文指南为基准文档。

源码仓库为私有。[公开分发仓库](https://github.com/dding-g/spit-releases)仅提供官方安装文件、更新和用户指南。

## 安装与使用

从 [Releases](https://github.com/dding-g/spit-releases/releases) 下载已发布的系统和 CPU 对应压缩包并解压。[网站](https://spit-ashy.vercel.app)。macOS 12 或更新版本：将 `spit.app` 复制到 Applications。Windows：将 `spit.exe` 放在自选文件夹中运行，需要 Microsoft WebView2 Runtime。不提供安装程序或登录自动启动。macOS 仅有 ad-hoc 签名，**没有 Developer ID 签名或公证**；Windows 没有 Authenticode 签名。Gatekeeper 或 SmartScreen 可能警告或阻止运行，请只信任可靠来源。

Apple silicon 选择 `macos-arm64`，Intel Mac 选择 `macos-amd64`，Windows x64 选择 `windows-amd64`，Windows ARM64 选择 `windows-arm64`。**尚未在 Windows 上验证运行、更新及重启行为**；交叉构建不代表运行验证。

首次启动会发现已注册的 Obsidian 仓库并优先选择最近使用的仓库，不会递归扫描整个磁盘。如果没有仓库，请在设置中选择文件夹。可以使用任何现有文件夹，无需安装 Obsidian。

- macOS `Cmd + \` / Windows `Ctrl + \`：显示或隐藏快速输入窗口。
- `Enter`：立即隐藏并提交到后台保存；输入法组字期间按 Enter 不会提交。
- `Esc`：隐藏并保留未提交草稿，**仅限当前应用会话**。普通退出后重新启动不会恢复；仅下述主动更新重启例外。
- 多行粘贴会合并成一行。空笔记不会保存，上限为 10,000 个 UTF-16 代码单元。
- 左键点击托盘／菜单栏图标可开关**只读历史面板**，默认显示今天。可选择所有已保存日期、跳转到前后有记录的日期或刷新。不提供编辑、删除、搜索，也不是常驻桌面／系统小组件。
- 托盘菜单也可打开历史、新建笔记及文件夹与语言设置。全局快捷键注册失败时可用新建笔记。关闭窗口不会退出应用，请用菜单中的退出。

支持**自动检测操作系统／浏览器语言**或持久保存的手动选择：英语、韩语、日语、简体中文、西班牙语、法语、德语、葡萄牙语。手动设置优先；不支持的语言和缺失译文回退到英语。切换语言会保留当前草稿。

## 更新与隐私

应用从 GitHub Releases 检查更新并在后台自动下载。设置中显示状态和错误，可手动检查，准备好后可重启。**只有用户点击重启才安装并重启**，不会自动打断输入。重启会等待进行中的保存和队列持久化，输入法组字期间会拒绝重启。当前未提交草稿会作为更新专用快照保存，并在更新后恢复；普通会话草稿仍不会长期保存。

安装前会验证 SHA-256 校验和及使用应用内固定公钥的 Ed25519 签名，验证失败即阻止安装。更新签名不等于系统代码签名、Apple 公证或 Windows 发布者信任。更新检查和下载访问 GitHub 及其下载主机，但不会上传笔记或仓库文件。仓库同步取决于其他软件的设置。

## 文件与恢复

选择 `chosenRoot` 后，笔记写入 `chosenRoot/admo/YYYY-MM-DD.md`。若所选文件夹本身名为 `admo`，则直接使用，不会创建 `admo/admo`。不会移动根目录已有的每日笔记。即使延迟保存，也使用提交时的本地日期和时间。

```markdown
- 09:12:04 买牛奶 <!-- admo:UUID -->
```

隐藏的 HTML 注释是恢复时用于防止重复的标识符，在源码视图中仍可见。正文按纯文本转义，不解释为 Markdown/HTML，原有文件内容会保留。历史面板只读取实际 `admo` 文件夹中的日期文件，而非整个仓库，也识别受支持的旧笔记标记。

提交的笔记先保存在本地 `state.json` 队列，再追加并同步到 Markdown，成功后才从队列移除。写入失败时继续保留队列，在设置和托盘显示错误，**每 5 秒**重试，重启后也会继续恢复。如果连本地队列都无法保存，则将提交内容还原为草稿。

排队笔记保留原来的目标位置，切换文件夹只影响新笔记。队列按顺序处理，因此较早的目标不可用时，后续笔记也会等待。恢复丢失的文件夹或访问权限后即可重试。损坏的状态文件**不会自动重置**：修复前请先保留错误提示中指明的文件。

本地状态路径（与 Markdown 文件夹分开）：

- macOS：`~/Library/Application Support/spit/state.json`
- Windows：`%AppData%\spit\state.json`

默认路径不存在 `spit` 状态时，会按 `admo`、`adhd-memo` 的顺序迁移旧状态，不覆盖已有新状态。为保持兼容，Markdown 文件夹和原有笔记标记仍用 `admo`。不会重命名、移动或删除仓库文件夹，排队笔记也保留原目标。

笔记和状态均为**未加密明文**。窗口隐藏不代表已完成持久保存：队列落盘前强制退出或断电可能丢失该次输入。追加中断可能留下不完整的行；恢复时会保留这些行并追加完整笔记。不保证抵御文件系统／设备故障，或编辑器、云同步工具的并发修改。
