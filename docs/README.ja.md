# spit

[English](../README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md)

Windows/macOS向けの小さな常駐メモアプリです。1行のメモをすばやく入力してローカルのMarkdownに保存します。シンプルな入力画面を事前に読み込み、ファイル保存はバックグラウンドで行います。基準となる文書は英語版です。

ソースリポジトリは非公開です。[公開配布リポジトリ](https://github.com/dding-g/spit-releases)には公式のインストール用ファイル、更新、利用者向けガイドのみを掲載します。

## インストールと使い方

[Releases](https://github.com/dding-g/spit-releases/releases)で公開されたOS・CPU別アーカイブを展開します。[ウェブサイト](https://spit-ashy.vercel.app)。macOS 12以降では`spit.app`をApplicationsにコピーします。Windowsでは任意のフォルダーに`spit.exe`を置いて実行し、Microsoft WebView2 Runtimeが必要です。インストーラーやログイン時の自動起動設定はありません。macOSはad-hoc署名のみで、**Developer ID署名・公証はありません**。WindowsはAuthenticode未署名です。GatekeeperやSmartScreenが警告・ブロックする場合があるため、信頼できる配布元だけを利用してください。

Apple siliconは`macos-arm64`、Intel Macは`macos-amd64`、Windows x64は`windows-amd64`、Windows ARM64は`windows-arm64`を選びます。**Windows上の実行と更新・再起動は未検証です**。クロスビルドは実行検証ではありません。

初回は登録済みのObsidian保管庫を検出し、最近使った保管庫を選びます。ディスク全体の再帰検索は行いません。保管庫がない場合は設定でフォルダーを選択します。既存の任意のフォルダーを利用でき、Obsidianは必須ではありません。

- macOS `Cmd + \` / Windows `Ctrl + \`：入力画面を表示・非表示。
- `Enter`：すぐに画面を隠し、バックグラウンド保存を要求。IME変換中のEnterでは送信しません。
- `Esc`：画面を隠し、未送信の下書きを**現在のセッション中のみ**保持。通常の終了・再起動では復元されません。以下の明示的な更新再起動のみ例外です。
- 複数行の貼り付けは1行になります。空のメモは保存せず、上限は10,000 UTF-16コード単位です。
- トレイ／メニューバーのアイコンを左クリックすると、**読み取り専用の履歴パネル**が開閉します。最初は今日を表示し、保存済みのすべての日付の選択、前後の保存日への移動、更新ができます。編集・削除・検索機能や常設のデスクトップ／OSウィジェットではありません。
- トレイメニューからも履歴、新規メモ、フォルダーと言語の設定を開けます。ショートカットの登録に失敗した場合は新規メモを使います。ウィンドウを閉じても常駐し、終了するにはメニューの終了を選びます。

言語は**OS／ブラウザーの自動検出**または保存される手動選択に対応します。英語・韓国語・日本語・簡体字中国語・スペイン語・フランス語・ドイツ語・ポルトガル語を用意しています。手動設定が優先され、未対応の言語や不足する翻訳は英語に戻ります。言語変更で現在の下書きは失われません。

## 更新とプライバシー

GitHub Releasesで更新を確認し、バックグラウンドで自動ダウンロードします。設定で状態・エラーの確認、手動確認、準備済み更新の再起動ができます。**利用者が再起動を押すまでインストール・再起動しません**。実行中の保存とキューの永続化を待ち、IME変換中の再起動は拒否します。未送信の下書きは更新専用に保存し、更新後に復元します。通常のセッション下書きを常時保存する機能ではありません。

インストール前にSHA-256チェックサムとアプリに固定された公開鍵によるEd25519署名を検証し、失敗時はインストールを止めます。更新署名はOSのコード署名・Apple公証・Windowsの発行元の信頼とは別です。更新確認・ダウンロードはGitHubと配信ホストに接続しますが、メモや保管庫ファイルは送信しません。保管庫の同期は他のソフトの設定に従います。

## 保存ファイルと復旧

`chosenRoot`を選ぶと`chosenRoot/admo/YYYY-MM-DD.md`に保存します。名前がすでに`admo`のフォルダーならそのまま使用し、`admo/admo`にはしません。選択したルートにある既存の日次ノートは移動しません。保存が遅れても送信時の現地の日付と時刻を使用します。

```markdown
- 09:12:04 牛乳を買う <!-- admo:UUID -->
```

非表示のHTMLコメントは復旧時の重複防止用IDで、ソース表示では見えます。本文はMarkdown/HTMLとして解釈されないようエスケープし、既存のファイル内容は保持します。履歴は保管庫全体ではなく実際の`admo`フォルダーの日付別ファイルを読み、対応する旧形式のメモ識別子も認識します。

送信したメモはまずローカルの`state.json`キューに保全し、Markdownへの追記・同期後にキューから削除します。書き込みに失敗するとキューに残り、設定とトレイにエラーを表示します。**5秒ごと**に再試行し、再起動後も復旧を続けます。ローカルキュー自体を保存できない場合は、送信内容を下書きに戻します。

待機中のメモは元の保存先を保持し、フォルダー変更は新しいメモだけに適用されます。順番に処理するため、先の保存先が利用できなければ後続も待機します。失われたフォルダーやアクセス権を戻すと再試行できます。破損した状態ファイルは**自動初期化しません**。エラーに示されたファイルを保全してから修復してください。

Markdownの保存先とは別のローカル状態ファイル：

- macOS：`~/Library/Application Support/spit/state.json`
- Windows：`%AppData%\spit\state.json`

既定の保存先に`spit`の状態がない場合、旧`admo`、次に`adhd-memo`の状態を移行し、既存の新状態は上書きしません。互換性のためMarkdownフォルダーと既存の識別子は`admo`のままです。保管庫フォルダーの改名・移動・削除は行わず、待機中メモの保存先も維持します。

メモと状態は**暗号化されていない平文**です。画面が隠れても永続化完了とは限りません。キュー保存前の強制終了や停電では入力を失う可能性があります。追記途中の終了では不完全な行が残ることがあり、復旧時はそれを消さず完全なメモを追記します。ファイルシステム・機器の故障やエディター・クラウド同期との同時変更は保証の対象外です。
