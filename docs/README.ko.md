# spit

[English](../README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md)

Windows·macOS용 작은 트레이 앱입니다. 한 줄 메모를 빠르게 입력해 로컬 Markdown으로 저장합니다. 간결한 입력창을 미리 로드해 두고 파일 저장은 백그라운드에서 처리합니다. 기준 문서는 영어 안내서입니다.

소스 저장소는 비공개입니다. [공개 배포 저장소](https://github.com/dding-g/spit-releases)에는 공식 설치 파일·업데이트·사용자 안내서만 제공합니다.

## 설치와 사용

[Releases](https://github.com/dding-g/spit-releases/releases)에서 공개된 OS·CPU별 압축 파일을 받아 해제하세요. [웹사이트](https://spit-ashy.vercel.app). macOS 12 이상에서는 `spit.app`을 Applications에 복사해 실행합니다. Windows는 원하는 폴더에 `spit.exe`를 두고 실행하며 Microsoft WebView2 Runtime이 필요합니다. 설치 프로그램과 로그인 자동 실행 설정은 없습니다. macOS는 ad-hoc 서명만 적용되며 **Developer ID 서명·공증은 없습니다**. Windows는 Authenticode 미서명입니다. Gatekeeper·SmartScreen이 경고하거나 차단할 수 있으므로 출처를 신뢰하는 파일만 여세요.

Apple silicon은 `macos-arm64`, Intel Mac은 `macos-amd64`, Windows x64는 `windows-amd64`, Windows ARM64는 `windows-arm64`를 선택하세요. **Windows 실제 실행과 업데이트·재시작 동작은 Windows에서 검증하지 않았습니다.** 교차 빌드는 실행 검증이 아닙니다.

첫 실행에는 디스크 전체를 재귀 검색하지 않고 등록된 Obsidian vault를 탐색해 최근 사용 vault를 선택합니다. 없다면 설정에서 폴더를 선택하세요. 기존 폴더라면 사용할 수 있으며 Obsidian은 필수가 아닙니다.

- macOS `Cmd + \` / Windows `Ctrl + \`: 입력창 열기·숨기기.
- `Enter`: 즉시 숨기고 백그라운드 저장 요청. IME 조합 중 Enter는 제출하지 않습니다.
- `Esc`: 숨기고 미제출 초안을 **현재 앱 세션에서만** 유지합니다. 일반 종료·재실행 시 복원되지 않으며, 아래의 명시적 업데이트 재시작만 예외입니다.
- 여러 줄 붙여넣기는 한 줄로 합칩니다. 빈 메모는 저장하지 않으며 최대 10,000 UTF-16 코드 단위입니다.
- 트레이/메뉴 막대 아이콘을 왼쪽 클릭하면 **읽기 전용 기록 패널**이 열리거나 닫힙니다. 기본은 오늘이며, 저장된 모든 날짜 선택·이전/다음 저장 날짜 이동·새로고침을 지원합니다. 편집·삭제·검색이나 상시 데스크톱/OS 위젯은 아닙니다.
- 트레이 메뉴에서도 기록, 새 메모, 폴더·언어 설정을 열 수 있습니다. 단축키 등록 실패 시 새 메모를 사용하세요. 창을 닫아도 상주하며, 완전히 끝내려면 종료를 선택합니다.

언어는 **OS/브라우저 언어 자동 감지** 또는 저장되는 수동 선택을 지원합니다. 영어·한국어·일본어·중국어 간체·스페인어·프랑스어·독일어·포르투갈어를 제공합니다. 수동 선택이 우선하며 지원하지 않는 언어와 누락된 번역은 영어로 표시합니다. 언어를 바꿔도 현재 초안은 유지됩니다.

## 업데이트와 개인정보

GitHub Releases에서 업데이트를 확인하고 백그라운드에서 자동 다운로드합니다. 설정에서 상태·오류 확인, 수동 확인, 준비된 업데이트의 재시작을 할 수 있습니다. **사용자가 재시작을 눌러야 설치·재시작**하며 입력 도중 자동으로 중단하지 않습니다. 진행 중 저장과 대기열의 영속 기록을 기다리고 IME 조합 중에는 재시작을 거부합니다. 현재 미제출 초안은 업데이트 전용으로 보존해 재시작 후 복원하며, 일반 세션 초안을 항상 저장하는 기능은 아닙니다.

설치 전 SHA-256 체크섬과 앱에 고정된 공개 키로 Ed25519 서명을 검증하며 실패하면 설치하지 않습니다. 이 업데이트 서명은 OS 코드 서명·Apple 공증·Windows 게시자 신뢰와 별개입니다. 업데이트 확인·다운로드는 GitHub와 다운로드 호스트에 접속하지만 메모·vault 파일은 업로드하지 않습니다. vault 동기화는 다른 프로그램의 설정을 따릅니다.

## 파일과 복구

`chosenRoot`를 선택하면 `chosenRoot/admo/YYYY-MM-DD.md`에 기록합니다. 이미 이름이 `admo`인 폴더를 선택하면 그대로 사용해 `admo/admo`를 만들지 않습니다. 선택한 루트에 있던 일간 노트는 옮기지 않습니다. 저장이 늦어져도 제출 시점의 현지 날짜·시간을 사용합니다.

```markdown
- 09:12:04 우유 사기 <!-- admo:UUID -->
```

숨겨진 HTML 주석은 복구 시 중복을 방지하는 식별자이며 소스 보기에는 표시됩니다. 메모는 Markdown/HTML로 해석하지 않도록 이스케이프하고 기존 파일 내용은 보존합니다. 기록 패널은 vault 전체가 아닌 실제 `admo` 폴더의 날짜별 파일을 읽으며 지원되는 이전 메모 표식도 인식합니다.

제출 내용은 로컬 `state.json` 대기열에 먼저 보존하고 Markdown에 추가·동기화한 뒤 대기열에서 제거합니다. 저장 실패 시 대기열을 유지하고 설정·트레이에 오류를 표시합니다. **5초마다** 재시도하며 재시작해도 복구를 이어갑니다. 로컬 대기열 자체에 보존하지 못하면 제출 내용을 초안으로 되돌립니다.

대기 메모는 원래 목적지를 유지하므로 폴더 변경은 새 메모부터 적용됩니다. 순서대로 처리하기 때문에 앞 메모의 폴더가 복구될 때까지 뒤 메모도 대기합니다. 사라진 폴더나 접근 권한을 복구하면 재시도합니다. 손상된 상태 파일은 **자동 초기화하지 않습니다**. 오류에 나온 파일을 먼저 보존한 뒤 복구하세요.

Markdown 폴더와 별개인 로컬 상태 경로:

- macOS: `~/Library/Application Support/spit/state.json`
- Windows: `%AppData%\spit\state.json`

기본 상태 경로에 `spit` 상태가 없을 때 기존 `admo`, 다음으로 `adhd-memo` 상태를 이전하며 새 상태를 덮어쓰지 않습니다. Markdown 폴더·기존 메모 표식은 호환성을 위해 `admo`를 유지합니다. vault 폴더를 이름 변경·이동·삭제하지 않으며 대기 메모의 목적지도 유지됩니다.

메모와 상태는 **암호화되지 않은 평문**입니다. 창이 숨겨졌다고 영속 기록이 끝난 것은 아닙니다. 대기열 기록 전 강제 종료·정전 시 입력을 잃을 수 있습니다. 추가 도중 종료하면 불완전한 줄이 남을 수 있으며 복구는 이를 지우지 않고 완전한 메모를 추가합니다. 파일시스템·장치 고장이나 편집기·클라우드 동기화의 동시 변경은 보장 범위 밖입니다.
